**Traceback Lab data card**

Three demonstrations originate from SWE-bench Lite and refer to Requests PRs 1963, 2674 and 3362. The supplied SQLite indexes contain production Python files at their exact base commits. Vendored Requests packages and test paths are excluded by the stored scope configuration.

Public cases, historical answers and source indexes have separate directories. The reveal endpoint retrieves the patch and mapped symbols in a separate request.

Each source record retains a content hash. Dataset viewer records were collected without a dataset revision pin, so exact row hashes and base commits are the reproducibility anchors. Revision-pinned loading is supported through the datasets extra.

Issue text has historical_text=unverified. Automated checks flag unified diffs, links to the same fixing PR and explicit solution language. Historical reconstruction and manual review remain part of a strict research dataset.

The audit report covers 30 records from Requests, Flask, pytest and seaborn. All 30 gold patches apply to their base trees. Twenty-eight have a supported function label. Two lie outside the candidate universe. This is a mechanical pipeline audit with unreviewed task types.

Labels use OLD coordinates, with explicit insertion boundaries, decorators, nesting and added symbols. Formatting, comments and detectable docstring-only changes are auxiliary. Mixed patches preserve their mapping coverage.

Patch application confirms source compatibility. Dynamic failure-before/pass-after reproduction is a separate status and remains not_run for the included demonstrations.

Temporal splitting groups identical changes while ignoring hunk offsets, groups identical query text, and moves a group by its latest fix availability. Held-out repositories are assigned as a whole. Timestamp certainty remains explicit.

Requests source retains its original copyright statements. License texts are in data/licenses. The implementation is under the project MIT license. Fonts retain their OFL files in frontend/public/fonts and compiled web assets.

The upstream task collection and repository are available from their publishers. [SWE-bench Lite](https://huggingface.co/datasets/SWE-bench/SWE-bench_Lite) [Requests](https://github.com/psf/requests)


The portable encoder was trained on docstrings paired with implementations from Python's installed standard library. The generator skips site-packages, bundled dependencies, tests and examples, removes each target function's own docstring and deduplicates tokenized queries and implementations. Upstream modules determine the validation split. The training journal identifies the Python version and the pair fingerprint. No uploaded user projects participate in training. Machine-generated hash-bucket weights, the trainer and a copy of the Python distribution license are included.

The release benchmark evaluates the supported cases from the 30-case audit after excluding every demo ID and matching fix group. It has 25 cases from four repositories. Model selection used standard-library validation only. Per-case predictions and metric definitions permit independent inspection.
